1. 정규화(Normalization)의 수학적 원리와 한계

Normalization

각 핵의 캡슐화 효율과 시퀀싱 깊이(Depth) 차이를 보정하여 순수한 생물학적 농도 차이를 추출합니다.

Shifted Log-Normalization (표준)

각 핵의 총 UMI를 10,000으로 스케일링 후 ln(x + 1) 계산.

sc.pp.normalize_total(adata, target_sum=1e4)
sc.pp.log1p(adata)

장점: 빠르고 직관적.
한계: 극저발현 유전자의 기술적 노이즈가 과장될 수 있음.

SCTransform (정규화 음이항 잔차)

각 유전자별로 깊이를 공변량으로 둔 일반화 선형 모델(GLM)을 적합하여 피어슨 잔차(Pearson Residuals) 산출.

인지: 기술적 샘플링 노이즈를 완벽 분리하여 전립선암 미세 아형 구분에 최적화.

2. 차원 축소의 기하학: 선형 PCA에서 비선형 UMAP까지

Manifold Learning

PCA: 직교 공분산 선형 투영

  • 2,500개 고변이 유전자(HVG)를 30~40개 주성분(PCs)으로 압축
  • 전역적 분산(Global variance) 보존 및 노이즈 제거
  • Elbow Plot을 통해 유의한 PC 수 결정

UMAP: 리만 기하학 기반 비선형 투영

  • 고차원 kNN 그래프의 국소적 위상(Local topology)을 2차원에 최적 배치
  • n_neighbors: 15~30 (작을수록 국소 파편화, 클수록 전역 구조)
  • min_dist: 0.1~0.4 (클러스터 뭉침 강도 조절)

⚠️ 절대 주의: UMAP 상의 두 점 사이의 거리는 생물학적 진화 거리나 실제 발현 유사도와 일치하지 않습니다. 시각화일 뿐 정량 지표가 아님을 항상 인지하십시오!

3. 그래프 클러스터링: Louvain의 결함과 Leiden의 승리

Community Detection

kNN 세포 연결망에서 모듈러리티(Modularity)를 극대화하여 세포 군집을 정의합니다.

Louvain의 치명적 결함

알고리즘 최적화 과정에서 물리적으로 연결이 끊어진(Disconnected) 세포 집단이 하나의 클러스터로 묶이는 오류가 종종 발생합니다.

Leiden 알고리즘 (표준 채택)

노드 정제(Node Refinement) 단계를 도입하여, 모든 클러스터 내부의 노드들이 완전히 연결되어 있음을 수학적으로 보장합니다.

# kNN 그래프 구축 및 Leiden 클러스터링
sc.pp.neighbors(adata, n_neighbors=25, n_pcs=35)
sc.tl.leiden(adata, resolution=0.8, key_added="leiden_res0.8")
sc.tl.umap(adata, min_dist=0.3)

Cell Type Markers
세포 계통 세포 유형 핵심 분자 마커 (Canonical Markers) 생물학적 의미
상피 (Epithelial) 기저세포 (Basal) TP63, KRT5, KRT14 기저막 줄기세포능; 암 발생 시 소실
관강세포 (Luminal) KRT8, KRT18, KLK3, ACPP, AR 안드로겐 의존적 분비 세포

5. 악성 암세포 vs 정상 관강세포 감별 (inferCNV)

Aneuploidy Inference

임상적 난제: 전립선 생검에는 정상 상피세포가 섞여 있으며, 둘 다 KLK3와 KRT8을 발현합니다.

정상 상피 및 기질/면역 세포

유전적으로 건강한 2배체 (Diploid) 유전체를 유지함. 염색체 대규모 변이 없음.

악성 전립선 선암 세포

대규모 염색체 복제수 변이(CNA) 및 이수성(Aneuploidy) 보유: 8p Del, 8q Gain(MYC), 10q Del(PTEN), 13q Del(RB1).

inferCNV 판별 원리

염색체 1번~22번 유전자 위치 순으로 발현량을 정렬한 뒤 100-유전자 이동 윈도우로 스무딩 ──► 2배체 참조세포(T세포/내피세포) 발현량을 감산 ──► 염색체 팔 전체의 발현 증폭/결손 신호가 확인되는 세포만을 '악성 종양 세포'로 확정!

6. 차등 발현 분석(DEG) 판정 3대 원칙

Differential Expression

단순히 p-value가 0.05 미만이라고 해서 진정한 생물학적 마커가 아닙니다.

1. Effect Size (log2FC)

log₂Fold Change > 1.0 (최소 2배 이상 발현 차이 보장)

2. 집단 내 보편성 (pct.1)

해당 클러스터 세포의 과반수 이상(> 50%)에서 발현될 것

3. 타 집단 특이성 (pct.2)

다른 클러스터 세포에서는 20% 미만으로만 발현될 것

# Wilcoxon Rank-Sum 기반 마커 검정
sc.tl.rank_genes_groups(adata, groupby='cell_type', method='wilcoxon', pts=True)
