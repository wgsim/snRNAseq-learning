1. 종단적 시계열 데이터와 Waddington-OT: 몬지-칸토로비치 최적 수송 & 싱크혼-크노프

Optimal Transport

파괴적 시계열 측정으로 인해 개별 세포의 연속 추적이 불가능한 불연속 세포 집단 사이에서, 엔트로피 정규화 최적 수송과 싱크혼-크노프 교대 사영을 통해 O(N2) 초고속으로 전이 결합 행렬을 도출합니다.

📐 핵심 메커니즘 인포그래픽 아키텍처 벡터 다이어그램 보기 (Waddington-OT & 싱크혼 수송 결합)

1. 칸토로비치 완화 (Kantorovich Relaxation)

  • 시점 t1과 t2의 불연속 확률 측도: μ = ∑ pi δxi, ν = ∑ qj δyj
  • 몽주의 1:1 결정론적 사상의 한계 극복 → 결합 확률 행렬 Γ ∈ ℝ+N1×N2
  • 유클리드 비용 행렬 Cij = ||xi - yj||22 하에서 최소 비용 수송:
minΓ ∈ Π(μ, ν) ∑i=1N1 ∑j=1N2 Cij Γij
  • 고전 선형 계획법의 O(N3 log N) 연산 병목 발생

2. 엔트로피 정규화 & 깁스 커널 (Cuturi 2013)

  • 음의 섀넌 엔트로피 페널티 항 도입:
minΓ [ ⟨C, Γ⟩ - ε H(Γ) ],   H(Γ) = -∑i, j Γij (log Γij - 1)
  • 라그랑주 쌍대성을 통한 깁스 커널(Gibbs Kernel K) 도출:
Kij = exp( - Cijε ),   Γ* = diag(u) · K · diag(v)
  • 싱크혼-크노프 교대 사영(u ← p / Kv, v ← q / KTu)으로 O(N2) 초고속 수렴

3. 불균형 최적 수송과 조상/후손 추적

  • 세포 증식 및 사멸률 g(xi) 반영: 쿨백-라이블러(KL) 발산 페널티로 질량 비보존계 완벽 모델링
  • 전이 확률 행렬 변환: Pot(i, j) = Γij* / ∑k Γik*
  • 조상 역추적(Pull-back: μanc = ΓT ν) 및 후손 예측(Push-forward: νdesc = Γ μ) 다중 시점 연쇄 결합

2. CellRank 2 다중 커널 융합: 속도 + 발달잠재력 + 실시간 커널의 볼록 결합

Multi-Kernel Fusion

단일 양식의 노이즈와 속도 왜곡을 극복하기 위해 속도, 발달 잠재력(CytoTRACE), 시계열 최적 수송(WOT), 공간 전사체 커널을 독립 추상화하고, 행-확률성이 엄밀히 보존되는 볼록 결합으로 마르코프 전이 행렬을 구성합니다.

📐 핵심 메커니즘 인포그래픽 아키텍처 벡터 다이어그램 보기 (다중 커널 융합 & G-PCCA 거시상태)

1. 단일 양식의 한계와 4대 커널 추상화

  • 속도 커널 (Pvel): 속도 vi와 변위 Δxij 간 피어슨 상관 rij 및 지수 온도 정규화
  • 의사시간/CytoTRACE 커널 (Ppt): 발달 잠재력 C(i) 기반 로지스틱 단방향 편향 f(Δtij)과 발현 친화도 결합
  • 실시간 커널 (Pot): 종단적 시계열 WOT 싱크혼 결합 행렬의 행 정규화
  • 공간 커널 (Psp): 조직 2D 물리 거리 및 리간드-수용체(LR) 상호작용 결합 (Track 02 연계)

2. 볼록 결합(Convex Combination)과 행-확률성

  • M개 개별 커널의 선형 가중 결합:
Pcomb = ∑m=1M wm Pm,   ∑m=1M wm = 1,   wm ≥ 0
  • 행-확률성 보존 수학적 증명:
Pcomb 1 = ( ∑m wm Pm ) 1 = ∑m wm (Pm 1) = ∑m wm 1 = 1
  • 모든 커널의 행합이 1이므로 결합 행렬 역시 엄밀한 마르코프 전이 행렬 보장

3. mCRPC 계통 가소성 융합 최적화

  • Enzalutamide 치료 시 전사 감속으로 인한 속도 음수 왜곡을 CytoTRACE 커널(wcyto = 0.5)로 보정
  • 속도 벡터(wvel = 0.5)의 국소 방향성과 CytoTRACE의 전역적 줄기세포능 경사가 결합하여 역류 아티팩트 완벽 제거
  • 시계열 샘플 존재 시 WOT 커널을 추가 결합하되 가중치를 재정규화(예: wot = 0.4, wvel = wcyto = 0.3, Σw = 1)하여 종단적 질량 수송 보존

3. 실 슈어 분해(Real Schur) & G-PCCA: 비가역적 마르코프 거시상태 식별

G-PCCA Macrostates

비가역적 세포 분화에서 세부 균형(Detailed Balance)이 파괴되어 고전적 대칭 스펙트럼 분해가 불가능함을 증명하고, 실 슈어 분해(Real Schur Decomposition)를 통해 느린 거시 동역학 불변 부분공간을 추출하여 4대 mCRPC 거시상태를 분해합니다.

1. 세부 균형 파괴와 비에르미트 분해

  • 생체 분화는 에너지(ATP)를 소모하는 비평형 개방계: πi Pij ≠ πj Pji
  • 엔트로피 생성률 σ > 0 및 전이 행렬 P의 비대칭성
  • 고유값이 복소수 평면(λ = a ± bi)으로 확장되어 고전적 에르미트 PCCA 알고리즘 적용 불가

2. 실 슈어 분해와 지배적 불변 부분공간

  • 직교 행렬 Q (QTQ = I)와 준상삼각 행렬 T로의 분해:
P = Q T QT,   P Qk = Qk T11
  • 기븐스 회전을 통해 상위 k개 지배적 고유값이 좌상단 블록 T11에 오도록 정렬
  • Qk ∈ ℝN×k가 시스템의 느린 거시 동역학(Slow Invariant Subspace) 완벽 포착
  • 스펙트럼 갭 Δk = |λk| - |λk+1| 극대화 지점에서 최적 거시상태 개수 k 결정

3. 심플렉스 투영 & 4대 mCRPC 말단 거시상태

  • Qk 좌표를 외접하는 최소 부피 정규 심플렉스 꼭짓점 탐색 → 소프트 소속도 행렬 χ 도출
  • 4대 mCRPC 말단 거시상태:
  • 1. AR+ 루미날 선암종: KLK3+, NKX3-1+ 호르몬 의존성 종착점
  • 2. 양분비성 암종 (Amphicrine): AR+ / CHGA+ 동시 양성
  • 3. 이중음성 전립선암 (DNPC): AR- / NE-, FGFR1+ / ETV4+ 침윤형
  • 4. 치료유발 신경내분비암 (t-NEPC): AR- / CHGA+ / SYP+, ASCL1+ / INSM1+
  • 가소성 중간체: KRT4+ / TACSTD2+ 줄기세포능 유지 전이 상태

4. 흡수 마르코프 체인 수리 도출: 기본 행렬 N & 운명 흡수 확률 행렬 B = NR

Absorbing Chains

전이 행렬을 정규 블록 형태로 분할하고, 스펙트럼 반경 ρ(Q) < 1에 기반한 노이만 급수 수렴 증명을 통해 기본 행렬 N과 흡수 확률 행렬 B = NR을 엄밀히 도출합니다.

📐 핵심 메커니즘 인포그래픽 아키텍처 벡터 다이어그램 보기 (흡수 마르코프 체인 & 운명 확률)

1. 정규 블록 분해 (Canonical Block Form)

  • N개 세포를 전이 세포 t개와 흡수(말단) 세포 r개로 인덱스 재배열:
P = [ QR0Ir ],   Q 1t + R 1r = 1t
  • Q ∈ ℝt×t: 전이 세포 간 전이 확률 (Qij ≥ 0)
  • R ∈ ℝt×r: 전이 세포에서 흡수 상태로 1단계 직접 진입할 확률

2. 기본 행렬 N과 노이만 급수 수렴

  • 흡수 상태 도달성 보장에 의해 스펙트럼 반경 ρ(Q) < 1 성립 → limk→∞ Qk = 0
  • 노이만 급수(Neumann Series) 항등식으로부터 역행렬 존재 엄밀 증명:
N ≡ (It - Q)-1 = ∑k=0∞ Qk
  • 기댓값 물리적 의미: Nij는 전이 세포 i에서 출발한 무작위 행보가 임의의 종착지로 흡수되기 전까지 전이 세포 j를 통과하는 총 기대 방문 횟수(Expected Number of Visits)

3. 흡수 확률 B = NR 도출 & GMRES 해석

  • 1단계 조건부 확률(First-step analysis): B = R + QB ⇔ (I - Q)B = R
B = (It - Q)-1 R = N R
  • 행합 보존 증명: B 1r = (I - Q)-1 (I - Q) 1t = 1t (확률 1로 어느 한 종착지로 흡수)
  • 10만+ 대규모 아틀라스에서 O(t3) 직접 역행렬 대신 GMRES 크릴로프 부분공간 반복법 적용

5. mCRPC 계통 가소성 추적: t-NEPC vs DNPC 분기 운명 & 계통 프라이밍 엔트로피

Lineage Plasticity

Enzalutamide 치료 압력 하에서 암세포가 선택하는 두 가지 상이한 탈출로(t-NEPC vs. DNPC)의 분기 메커니즘을 규명하고, 계통 프라이밍 엔트로피(Hi)를 통해 치료적 차단이 가능한 가소성 교차로를 동정합니다.

1. t-NEPC vs DNPC 양방향 분기 스위치

  • t-NEPC 분기 (신경내분비 분화): TP53/RB1 동시 결손 하에서 뉴런 전사인자(ASCL1, INSM1) 및 EZH2 급증, CHGA+/SYP+ 발현 및 신경 분화 완결
  • DNPC 분기 (이중음성 분화): RB1 보존 상태에서 FGFR1/MAPK 활성화 및 ETV4/SOX9 과발현, 상피-중간엽 전이(EMT) 기질 침윤
  • AR 저해제에 대한 생물학적으로 완전히 직교하는 두 갈래의 저항성 회피 경로

2. 계통 프라이밍 엔트로피 (Entropy: H_i)

  • 흡수 확률 분포 Bi·의 섀넌 엔트로피를 통해 세포의 미분화 가소성 수준 정량화:
Hi = - ∑k=1r Bik log Bik
  • Hi ≈ 0: 특정 운명으로 이미 비가역적 결정이 완료된 세포 (Commitment)
  • Hi ≥ 1.8 (극대화, 상한 log24 = 2 bit): AR 선암종·Amphicrine·DNPC·t-NEPC 4대 계통 어느 쪽으로도 분화 가능한 다분화능 가소성 교차로 (Bifurcation Checkpoint)

3. Pre-existing vs De Novo 가소성 판별

  • Pre-existing 모델 (치료 전 기배정): 치료 전 생검의 scCNA 상에서 17p(TP53)/13q(RB1) 결손 클론이 0.1~1% 수준으로 이미 검출되며 Bt-NEPC > 0.85 기록
  • De Novo 적응 모델 (치료 유도 가소성): 치료 전 정상 유전체(Bt-NEPC ≈ 0)였으나 약제 노출 후 EZH2 크로마틴 리모델러 활성화 및 Hi 피크를 거쳐 단계적 획득

6. 계통 마스터 드라이버 발굴: 음이항 GAM 스플라인 & 파이오니어 전사인자 동정

Driver Discovery

흡수 확률 벡터 bk와 유전자 발현 간의 비선형 음이항 GAM 스플라인 적합을 통해, 단순 말단 지표(Passenger Marker)와 세포 운명을 결정하는 파이오니어 선도 인자(Pioneer Driver)를 시간-동역학적으로 감별합니다.

1. 흡수 확률 상관 및 음이항 GAM

  • 운명 확률 bk와 유전자 xg 간 피어슨 및 스피어만 순위 상관 분석
  • 음이항(Negative Binomial) 일반화 가법 모델(GAM) 큐빅 스플라인 적합:
log(μig) = β0 + sg(Bik) = β0 + ∑m=1M βgm φm(Bik)
  • 단일세포 카운트의 과분산 및 드롭아웃을 보정하고 일시적 펄스(Transient Pulse) 유전자 감지

2. 활성화 시점(B_onset)과 t-NEPC 드라이버

  • 1차 도함수 s'g(B)로부터 유전자가 급상승하는 임계 시점 Bonset 정량화:
  • 조기 후성유전 프라이밍 (Bonset ≈ 0.2~0.3): EZH2, SOX2 (크로마틴 응축 해제 및 다분화능 개방)
  • 파이오니어 전사인자 (Bonset ≈ 0.4~0.5): ASCL1, INSM1 (폐쇄된 신경 염색질 부위 직접 결합)
  • 치료 표적 리간드: DLL3 (Notch 억제 리간드, t-NEPC 특이적 ADC 표적)
  • 말단 기능성 마커 (Bonset > 0.85): CHGA, SYP (분화 완결 후 축적되는 단순 패신저 마커)

3. DNPC 드라이버 및 멀티옴 교차 검증

  • DNPC 특이적 드라이버 캐스케이드: FGFR1 증폭 → ETV4/SOX9 regulon 전사 활성화 → TWIST1 침윤
  • 멀티오믹스 교차 검증: Track 01 SCENIC+ eGRN regulon 활성 점수(AUCell) 및 Track 04 scCNA 서브클론 변이와의 유기적 융합
