- 파이프라인 순서(raw matrix → CellBender → QC → Scrublet)와 CellBender가 **raw** 행렬을 입력으로 요구한다는 설명: 정확. `--fpr` 방향(값을 키울수록 더 많은 noise 제거; 기본 0.01은 보수적)도 CellBender 문서와 일치(08 이슈 1).
- Cell Ranger ≥7.0에서 `--include-introns` 기본 true: 10x 문서와 일치. STARsolo `GeneFull`이 엑손+인트론 합산이라는 설명, STARsolo "~10배 빠름" 서술(공식 문서 주장), 바코드 조합 수 계산(4^16, 4^12): 정확.
- Pseudoreplication 개념 자체(세포≠독립 반복, 환자 단위 집계/GLM) 및 대응 표본 설계 `~ patient_id + condition`의 취지: 정확.

- 마커 유전자 표(05), AR LBD 변이(T878A/W742C/F877L)와 t-NEPC 분자 특성(TP53/RB1, SOX2, EZH2, REST 소실), 8p/8q/10q/13q/17p/Xq 유전자 위치: 대체로 정확.
- Scrublet이 관측 전사체 쌍을 합쳐 인공 doublet을 만든다는 설명과 Wilcoxon/MAST, 사본수 도구(infercnvpy 인자 window_size/step) 등 다수 API 이름·기본값: 정확.
