# Track 05 사실 검수 (eng-verifier, Batch 4)

- 대상: `tracks/05_generative_foundation_models/docs/00~09_*.md` (10개 챕터, 3,818줄) + `docs/images/*.svg` 6개 + `pipelines/results_pipeline_0{1,2}`(교차 대조용). 표의 경로는 `tracks/05_generative_foundation_models/` 기준.
- 방식: (1) 수식·수치 재계산(NB 모멘트, KL, 어텐션 분산, 코사인 분산 1/d, 메모리 산술 등), (2) 문서의 Python 블록 10개를 추출해 scvi-tools 1.5.1 / torch 2.14.1 환경(`.venv_api`)에서 실행(합성 데이터, 에포크만 축소), (3) scvi-tools 소스·시그니처 직접 조회와 0.20.3~1.5.1 태그별 기본값 비교, (4) scGPT/Geneformer 공개 코드·모델카드 대조, (5) PubMed/arXiv/ClinicalTrials 계열 서지 대조.
- 확신도: Confirmed(직접 실행·소스·서지 근거) / Plausible(근거 없음 또는 간접). S1/S2는 외부·실행 근거가 있는 항목만 Confirmed로 두었고, 근거가 약한 것은 Plausible 표기.
- 한계: scGPT 논문 본문(Nature Methods)은 접근 불가(Nature 로그인 리다이렉트, bioRxiv 403)였다. scGPT 사전학습 목표는 **공개 저장소 코드**(`scgpt/model/model.py`, `data_collator.py`, 튜토리얼)와 Geneformer 모델카드로 대조했다.
- Track 00 교차 확인: SCI-00-058(z 배치 완전 소거 과장), SCI-00-059(`categorical_covariate_keys`에 생물학 요인 투입), SCI-00-060(batch_key=patient 과보정), SCI-00-061(gene_likelihood 기본값). 아래 SCI-05-008·009에서 연결.
  - `categorical_covariate_keys` 자체는 Track 05(ch02 L311)에서 `sequencing_protocol`(교란 요인)에만 쓰여 SCI-00-059와 **직접 모순 없음**. 다만 `batch_key="patient_id"`(ch02 L310, ch03 L207)는 SCI-00-060과 같은 긴장을 공유한다.
  - gene_likelihood 기본값은 **Track 00과 Track 05가 서로 반대로 서술**한다(Track 00: zinb 맞음, Track 05 ch01 L167: NB 기본이라 서술 → 틀림. SCI-05-009).
- 기존 ENG 항목: ENG-009(`scvi.data.prepare_query_anndata`)는 중복 기록하지 않고 SCI-05-024에서 **후속 문제**(수정 후 반환값)만 기록. ENG-033(파이프라인이 자체 구현 모사)은 SCI-05-001의 배경.

## 요약

- 총 52건: S1 1 / S2 23 / S3 28.
- S1 (SCI-05-001): 그림(SVG 01·03·06)과 생성 스크립트에 하드코딩된 성능 수치(iLISI 0.94, scANVI 정확도 98.4%, 계통 역전 "82% 억제", IC50 "8.4배")가 **이 트랙 자신의 파이프라인 산출물과 정면 충돌**한다(실제: scANVI 미라벨 정확도 0.557, 잠재 iLISI 정규화 0.556·배치 혼합 개선 −1.9%, 이중 KO 억제 2.48%). 근거 없는 정량 "결과"가 임상 메시지(감수성 8.4배 회복)와 결합돼 있다.
- S2 주제
  - 코드: ch00 NB 검증 코드의 `probs` 반전(평균이 μ가 아니라 ≈0.15, 로그우도 −114.9 대 정답 −9.55), ch02 `get_normalized_expression` 주석("배치 제거")과 DE 호출(존재하지 않는 군집명 → ZeroDivisionError), ch03 `KeyError: 'scvi_normalized'`, ch04 "불변성 검증"이 동일 모델끼리 비교하는 **항진 검사** + `weight_decay=1e-6`이 불변성을 깸(실측 드리프트 2.05e-5, 튜토리얼은 0.0 권고), `prepare_query_anndata` 기본 `inplace=True`가 None 반환(ENG-009 후속), ch07 `In_Degree`가 모든 유전자에서 정확히 1.0, ch08 `scgpt_model_mock` 임포트 불가.
  - 사실: ch01 "scVI 기본 우도는 NB"(0.20.3~1.5.1 전 버전 zinb), Ahlmann-Eltze&Huber 2023 오귀속(로그+의사카운트가 동등/우수라는 결론), scGPT 사전학습 목표 오기술(MGM/CTC는 Geneformer·지도학습 개념; scGPT는 값 마스킹 GEP/GEPC), 제로샷 배치 소거 단정(Kedzierska 2025와 상충), Geneformer rank-value 인코딩에서 코퍼스 유전자별 정규화 누락, 어텐션=조절망 단정과 "ASCL1 프로모터 재배선", 섭동 예측 성능 서술이 Ahlmann-Eltze 2025(선형 기준선 미돌파)를 누락, DP로 역추적 "수학적으로 완벽히 불가능", 가상 스크리닝 수치("입증/가상으로 규명")가 난수 모델·무데이터, Tarlatamab "가장 강력한 대안"(DLL3 양성 일부).
  - 서지: 존재하지 않는 DOI(Dong et al. Science 2020), He et al. 쪽수(426–433)·Labrecque 저널(JCI) 오류.
- 수식·산술은 대체로 정확(ledger 참조): NB 유도·모멘트·PMF, KL 폐형식, ELBO 분해, 어텐션 스케일링 분산 d_k, 코사인 분산 1/d(MC 실측 0.001951 대 0.001953), 메모리 산술(16 MB/1.6 GB, 6.144e8), P(X=0)=0.952, 역심슨 최댓값 B, Kingma M2 비레이블 손실, 롤아웃 정의. ch01의 NB·ZINB 손실 구현은 scvi.distributions와 7.6e-6 이내로 일치(양호).

## 잘된 점

- **수식 유도가 대체로 정확**: NB의 Gamma-Poisson 유도·PMF·모멘트(ch01), 가우시안 KL 폐형식과 ELBO 분해(ch02), Kingma M2 비레이블 손실(ch03), 어텐션 1/√d_k 분산 유도(ch05), 코사인 분산 1/d(ch08: MC 실측 0.001951 대 이론 0.001953), 역심슨 최댓값 B와 코시-슈바르츠 논증(ch09), 롤아웃 정의(Abnar & Zuidema; ch07 Q2의 마르코프 수렴 논증)가 모두 재계산·시뮬레이션과 일치.
- **손실 구현의 정확성**: ch01의 `NegativeBinomialLoss`/`ZeroInflatedNegativeBinomialLoss`는 `scvi.distributions` NB/ZINB와 최대 오차 1.1e-5·7.6e-6으로 일치(θ∈[1e-4,1e2]). ch02의 경량 VAE(`SingleCellVAE`)는 실행·역전파 정상(library_prior만 텐서 필요).
- **scvi-tools API 사용이 대체로 최신과 호환**: `setup_anndata`(layer·batch_key·labels_key·categorical/continuous covariate), `SCVI(...)` 인자 전부, `SCANVI.from_scvi_model(…, unlabeled_category, labels_key, adata)`, `predict(soft=True)`, `load_query_data(freeze_* …)`의 키워드 이름이 1.5.1에서 유효. `categorical_covariate_keys`는 교란 요인(시퀀싱 프로토콜)에만 사용돼 SCI-00-059와 충돌하지 않음.
- **Geneformer 수치·구조**: 6층/256/4헤드/512/입력 2048/어휘 25,424는 V1 설정과 일치(SCI-05-043은 버전 명시만 요구). MYC 전역 증폭이 순위 인코딩의 맹점이 된다는 서술(ch07 Q1)은 타당. 토큰 삭제 ISP의 순위 이동 서술(ch08 Q1)도 정확.
- **메모리·계산 산술**: 20,000² 어텐션 1.6 GB 대 2,000² 16 MB, 1,024×200×3,000=6.144e8, P(X=0)=0.952 등이 정확. scANVI의 비레이블 비용이 O(K)라는 서술은 구현과 일치.
- **정직한 구분 문구**: ch06 코드 docstring이 "사전학습 가중치 구조를 모사"라고 밝히고, ch05 코드는 임베딩/마스크 흐름이 실행·형상 검증까지 통과(경고만 존재).
