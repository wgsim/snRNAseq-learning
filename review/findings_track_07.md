- 총 69건: S1 3 / S2 35 / S3 31

- S2 주제: NEBULA 속도 기전·LN/HL 정의 오류, Milo Spatial FDR 수식/가중치 오기술, scCODA 사전분포·기준 세포형·임계값 오기술, 재현 불가 시뮬레이션 출력(84.6% vs 실제 ~76%), 수치 오류(t>50, 검정력), 코호트 서술 불일치(GEO와 상이), Poisson-GLM 검정력 코드, RUV 처방 오류.

## Track 00과의 모순·교차 확인

1. pseudobulk 지위: Track 00 08장 Q1은 'pseudobulk가 Type I error를 제어하는 유일한 표준'(SCI-00 지적 대상), Track 07은 GLMM/NEBULA도 유효하다고 제시 → 문구 통일 필요(위 교차 행). Track 07의 02·03장 pseudobulk 원리(공여자 단위 집계, 라이브러리 크기·EB 수축)는 Track 00과 대체로 일치.
2. 코호트 수치: Track 00(Kfoury n=26, Chen n=13 원발+CRPC)·Track 07(Kfoury 15명, Chen 18명)·GEO(Kfoury PCa 환자 9명/25샘플 + 양성 7, Chen 원발 12 + LN 1)가 모두 다름. Track 00 SCI-00-004(Chen) 근거를 GEO 샘플 특성('12 primary + 1 lymphatic metastasis')으로 보강 가능.
3. 드롭아웃 용어: Track 07 01장('드롭아웃 없음')과 03·06장('기술적 드롭아웃')이 서로 모순, Track 00 Ch01도 동일 혼재.
4. 환경: Track 07은 버전 고정(양호, decoupler 1.8.0에서 get_pseudobulk 동작), Track 00은 무고정(SCI-00 지적). min_counts 기본값 500(Track 00) vs 1000(Track 07)로 상이.
5. DNPC/t-NEPC 분기 모형(06장)은 Track 00 4-state 틀을 그대로 전제 — 해당 틀의 출처 오귀속(Tang 2022) 이슈가 상속됨.

## 잘된 점 (정확/고품질)

- 01장: Poisson MGF 유도, Gamma–Poisson 적분 → NB PMF, Var=μ+μ²/θ(전체 분산 법칙), θ→∞ 극한, ZINB 식 구성, 샌드위치 분산 비 (1+αμ̄)와 Wald 팽창(α=0.5, μ̄=20 → 11배, 귀무 기각률 ≈55%) 및 Q3 CV 수치가 모두 정확.
- 02장: 급내상관·VIF·N_eff=NM/(1+(n−1)ρ), 극한 N/ρ, 표(41.4/100.8/117.8/119.5)와 Q1 N_eff≈488 계산 정확. 실험 단위 vs 측정 단위 논리가 명확.
- 03장: Jensen 부등식 논거, NB 우도, DESeq2 MAP 분산 수축(정규 사전, 추세 중심), QL 분산 모형과 F(k, d0+d_g) 구조, paired 설계 df=N−1, '정규화 평균을 DESeq2에 넣지 말 것' 원칙이 정확.
- 04·05장: Laplace 근사 식, 블록대각 Fisher 정보의 합 분해, Sherman-Morrison 역행렬 항등식과 O(n_j) 벡터곱 계산은 수학적으로 정확(단, NEBULA 속도 기전으로는 부적절).
- 07장: kNN 이웃 정의(인덱스+이웃), 인덱스 비율 prop≈0.1, edgeR QL 기반 NB GLM, `fdr.weighting="graph-overlap"` 등 miloR 함수/인자 이름, 오프셋 누락의 10배 편향 계산이 정확.
- 08장: ΣCov(p_j,p_c)=−Var(p_j) 증명, Aitchison 거리·CLR, scCODA 코드 API(from_scanpy, CompositionalAnalysis, sample_hmc, credible_effects, set_fdr)와 Dirichlet-multinomial 구조.
- 09장: 공여자 대 세포 수 분산 성분 논리와 SE 수치 계산, IHW의 '영가설 하 독립' 조건, 원시 카운트+배치 공변량 원칙(§2.1), DESeq2 `results(filterFun=ihw)` 사용법이 정확.
