# Track 09 과학적 정확성 검토 (sci-checker)

- 대상: `tracks/09_upstream_alignment_bam/docs/00~09_*.md` (10개 챕터; Master_Book·pipelines·scripts 제외). 읽기 전용.
- 방식: STAR 파라미터·STARsolo 동작은 STAR 소스(parametersDefault, ParametersSolo.cpp 등)와 문서, alevin-fry·pyroe·libradicl은 소스/문서, UMI-tools는 논문(Smith 2017)·소스, SAM/BAM은 hts-specs(SAMv1.tex), pysam은 소스, 좌표는 UCSC hg38 RefSeq/서열 API, 약리·분자 문헌은 Europe PMC/PubMed로 대조하고 수식·산술은 직접 재계산. `fetch(chr, x, x)`는 htslib 1.24로 직접 실행해 확인.
- 한계: 10x 화이트리스트 파일은 내려받지 않아(다운로드 승인 없음) 줄 수를 직접 세지 못하고 Cell Ranger raw 매트릭스 차원으로 교차 확인. alevin-fry/salmon/STAR 명령은 설치 없이 소스·문서 대조로 판정(실행 검증 아님). 10x BAM 문서 일부는 접속 제한(429)으로 검색 요약에 의존.
